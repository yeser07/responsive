# Frontend — CI Manager

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

`VITE_API_URL` must point to the API (e.g. `http://localhost:3000/api`).

## Scripts

- `npm run dev` — Vite dev server
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run test` — Vitest unit tests
- `npm run preview` — preview production build
